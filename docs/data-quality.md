## 1. 定位(用户 2026-10-15 定性,作为决策记录)

- **交付物 = 合格的参考数据,不是训练实验**。训练线冻结(S9 全程训练、探针对比分析、窗口存活评测全部取消),解冻条件 = 双舞数据全过全部不变量;
- **训练不能修数据**:策略对坏参考只有两条路——跟着做(抖动/翘脚照搬)或绕开做(低通/衰减/漂移=保真损失)。F10/V2 在 70% 不可行参考上的 3/3"通过",正是"绕开做"的代价:腿不像视频里的真人。真正属于策略侧的问题(深蹲墙=观测盲)已由 obs-v2 解决;剩余全部是数据侧问题;
- 验收从"数字报表"改为"**机器判定的不变量**",人只读 PASS/FAIL,不再逐帧目检。

### 重定向层(GMR)
原点缩放浮脚(+5.3cm,两舞一致)、per-frame QP 盆地翻转瞬移(ws 版已修)、脚朝向任务照抄估计层伪影。

### 投影层(project_g1 v1 的三缺陷,2026-10-15 用户目检发现)
1. **软放平→翘脚**:放平目标带混合权重且 IK 受膝伸直限制,残余倾斜保留;且只约束"最低点贴地"(点约束),没约束"四角贴地"(面约束);
2. **±1.5cm 接触容差带→悬脚**:沿用 R 系列惯例只抬穿透不压浮空,接触帧最高留 1.5cm 间隙;
3. **去折角后无重钉→穿地**:de-kink 事后混合关节,把钉好的脚压回地面(终测最深 −9~16mm,报告里印着但不在 PASS 清单里)。

### 流程层教训(为什么会漏过)
- **百分位报表 ≠ 验收**:p50/p90 把最坏帧平均掉,人眼看到的恰是最坏帧;
- **单向流水线无闭环**:每个 mutation 阶段改写前一环结果,改完不复测;
- **指标继承先例而非物理**:"四角贴地"这个面约束不在 R 系列指标里,缺陷对门禁不可见;
- **以"优于手工链"为门禁是比较偏差**:2-4 倍好于手工链 ≠ 合格。

## 3. 解决框架:不变量 + 闭环(machine-verifiable acceptance)

**物理不变量(= 人眼在检查的东西,门禁一律取最坏帧)**

| 相位 | 不变量 | 门禁 |
|---|---|---|
| 站立相 | 脚底**四角** z ∈ [−2mm, +2mm]（同时消灭穿透/浮空/翘脚） | max |
| 站立相 | 脚 XY 速度 ≤ 0.05 m/s | max |
| 摆动相 | 净空 > 2cm,永不穿地 | max |
| 全程 | 关节限位内;帧步长 ≤ 真人节奏合理上界(分级平滑后) | max |
| 全程 | ZMP 出界率与根位移在忠实度预算内 | 预算制 |

**闭环结构**:每个 mutation 阶段(钉足/ZMP/去折角/平滑)后自动复测全部不变量 → 违规帧回炉该阶段(带回退梯子:膝伸直顶死时先松倾角再松 z、保 XY 钉)→ ≤3 轮 → 仍违规则显式标记 `IK_INFEASIBLE`(帧号+残差)进验收报告 → 最终输出逐条 PASS/FAIL。**"报数"不等于"验收",验收必须是最坏帧门禁的机器判定。**

## 4. 拓展路线(优先级序)

1. **project_g1 v3**:不变量闭环落地(四角贴地硬目标、钉足放最后不被去折角破坏、每步复测回炉)——设计已完成,待实现;
2. **分级平滑治抖动**:速度阈值区分真人快动作 vs 估计噪声,根/关节分级平滑,修完复测不变量(一直被搁置,正式入列);
3. **双舞全过不变量** → 机器验收报告(take6 + take2);
4. **take1 新视频全链零人工**:视频 → GVHMR → GMR → project_g1 → 不变量 PASS(泛化终测,也是本路线的里程碑);
5. **ViTPose 脚部关键点前端升级**(治源头:带脚尖/脚踝关键点的检测器,评估对踝伪影的收窄)——快赢,机会性执行;
6. **calibrate_smplx 泛化件**:SMPL-X 域 z 锚定/平滑写回 .pt(管线完整性,非试点必需);
7. 研究级(记录不阻塞):HuMoR 式学习型动作先验、GVHMR 内嵌物理损失、机器人感知估计器;
8. 远期愿景:视频直出机器人可行动作(端到端);
9. **训练线解冻**:数据全过后,训练降级为下游消费者(任何配方),不再是研究对象。
