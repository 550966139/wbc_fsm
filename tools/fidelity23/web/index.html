指标口径

  • fsr_ref：参考支撑相中足底水平速度 >0.10 m/s 的帧占比（GMD 分类法）
  • float：参考支撑相中鞋底悬空 >5mm 的时长占比（入场吊带期已排除）
  • mpjpe：世界系 24 刚体位置误差（入场帧刚体对齐后），p50
  • apex：踢腿窗(8.5–12s) 左鞋底最高高度 / 本版参考链同窗最高高度
  • drift：结尾段(td≥28.5s) 骨盆净位移 / 路径长
  • ankle：支撑踝距机械限位(−0.8727 rad) 余量

分类法来源：Mimicking-Bench (arXiv 2412.17730)、BeyondMimic (arXiv 2508.07200)
